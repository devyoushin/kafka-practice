# Kafka Docs

Kafka 문서는 학습 문서, 규칙, 템플릿, 에이전트 프롬프트를 함께 관리합니다.

| 폴더 | 내용 |
|------|------|
| `core-concepts/` | Broker, Topic, Partition, Consumer Group |
| `producer-consumer/` | Producer/Consumer 설정, Exactly-Once |
| `operations/` | Topic 관리, Consumer Lag, Rebalance |
| `security/` | SASL, TLS, ACL |
| `observability/` | JMX 지표, Lag 모니터링 |
| `rules/` | 문서 작성 및 운영 규칙 |
| `templates/` | 서비스 문서, 런북, 장애 보고서 템플릿 |
| `agents/` | Claude 에이전트 프롬프트 |

처음 읽을 문서는 `core-concepts/kafka-architecture.md`입니다.
