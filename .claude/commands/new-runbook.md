`$ARGUMENTS`를 파싱하여 운영 Runbook을 생성합니다.
- 첫 번째 인자: 대상 카테고리
- 나머지 인자: 작업명

## 파일 생성 규칙

1. 파일명: `runbook-{작업명}.md`
2. 저장 위치: `docs/{해당 카테고리}/`
3. `docs/templates/runbook.md` 템플릿 기반으로 작성

## 작성 시 필수 포함 사항

- **사전 체크리스트**: 최소 4개 항목
- **환경 변수 설정**: `export` 형식으로 명시
- **단계별 명령어**: 복붙 즉시 실행 가능
- **확인 명령어**: 각 스텝 완료 후 검증 명령어
- **롤백 절차**: 되돌릴 수 있는 명령어 포함
- **모니터링 포인트**: 작업 후 확인할 Prometheus 지표

## 작업 특성별 추가 요소

| 작업 유형 | 추가 항목 |
|----------|---------|
| Topic 변경 | 파티션 수 변경 이력, Rebalance 영향 범위 |
| Consumer 오프셋 리셋 | 리셋 전 Lag 스냅샷, 영향 Consumer Group 목록 |
| 보안 정책 변경 | ACL 변경 전후 비교, 영향받는 클라이언트 목록 |
| 클러스터 업그레이드 | Strimzi 호환성 확인, 롤링 업그레이드 순서 |
