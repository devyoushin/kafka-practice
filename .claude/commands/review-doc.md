아래 기준으로 `$ARGUMENTS` 문서를 검토하고 개선점을 제안해 주세요.

## 검토 항목

### 1. 구조 완성도
- [ ] 5개 필수 섹션(개요/설명/트러블슈팅/모니터링/TIP) 모두 존재하는지
- [ ] 각 섹션이 충분한 내용을 담고 있는지

### 2. 코드 품질
- [ ] 모든 코드 블록에 언어 태그가 있는지 (`bash`, `yaml`, `properties`)
- [ ] 플레이스홀더가 `<VALUE>` 형식으로 명확히 표시됐는지
- [ ] kafka-topics.sh 예시에 `--bootstrap-server` 가 포함됐는지

### 3. 보안 검토 (`docs/rules/security-checklist.md` 기준)
- [ ] ACL 예시가 최소 권한 원칙을 따르는지
- [ ] SASL/TLS 설정 권장 여부가 명시됐는지
- [ ] 와일드카드 리소스 사용 시 주의 문구가 있는지

### 4. 모니터링 섹션
- [ ] 관련 JMX/Prometheus 지표가 포함됐는지
- [ ] Consumer Lag 확인 방법이 있는지

### 5. 한국어/영어 병기
- [ ] 기술 용어에 영어 원문이 병기됐는지

## 출력 형식

```
## 검토 결과: {파일명}

### 잘된 점
- ...

### 개선 필요 사항
1. [섹션명] 문제 설명 → 개선 방안

### 보안 이슈 (있을 경우)
- 위험도: High/Medium/Low
- 내용: ...
```

검토 후 사용자 확인을 받아 수정 작업을 진행할지 물어보세요.
